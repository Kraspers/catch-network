# Minimal AI Web v3

React + Vite demo веб-приложения AI-чата.

## Что изменено
- очень округлые pill-сообщения пользователя;
- плавные появления сообщений, меню, модального окна и AI-анимация «анализирует»;
- светлая/тёмная тема;
- рабочие три точки у каждого чата: переименование/удаление;
- копирование каждого сообщения, и пользовательских, и AI;
- кнопка остановки генерации;
- график функции `y = x²`;
- блоки кода с отдельной кнопкой копирования;
- таблицы;
- прикрепление изображений;
- сохранение интерфейса, чатов и настроек в localStorage;
- более чистая компоновка в стиле современных AI-приложений.

## Запуск
```bash
npm install
npm run dev
```

## Render
Создай **Static Site**:
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

Настоящий AI пока не подключён: функция `mock()` в `src/main.jsx` специально сделана отдельной, поэтому позже её можно заменить запросом к `/api/chat` или другому backend API.

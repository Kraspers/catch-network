# Minimal AI — Web App

Веб-приложение на React + Vite.

## Запуск

```bash
npm install
npm run dev
```

После этого Vite покажет локальный адрес в терминале.

## Уже реализовано

- минималистичный адаптивный интерфейс;
- создание, выбор, переименование и удаление чатов;
- история чатов через localStorage;
- поиск по чатам;
- локальная память с включением/выключением;
- прикрепление изображений;
- demo-решение линейных уравнений;
- demo-график;
- demo-таблица;
- архитектура, где mockReply можно заменить реальным AI API.

## Подключение настоящего AI

Для production лучше сделать серверный `/api/chat`, чтобы API-ключ не попадал в браузер.

Frontend уже отделён от mock-логики: функцию `mockReply()` можно заменить вызовом backend.
